# 移液方案预演工具（Pipette Protocol Sandbox）

实验室技术员编排 96 孔板连续稀释方案时，用本工具在上机前预演，提前发现：

- **吸空** —— 转移/弃去体积超过孔内余量；
- **溢出** —— 加样或注入后单孔超过 **200 µL** 容量；
- **未混匀转移** —— 源孔刚接收过液体却没有先混匀，吸出液体不能代表当前浓度；
- **吸头跨样本带入** —— 复用吸头上残留的样本接触了另一组孔（或尚未接样的纯稀释液孔）。

遇到任一问题，推演**停在首次失败的步骤**，给出失败类型、原因和受影响孔位；此前已成功的状态可用滑块逐帧回看。

## 内置方案

打开即是 **A1→A8 二倍稀释**（共 24 步）：

| 孔 | 初始内容 |
|---|---|
| A1 | 200 µL、100 µM 样本 |
| A2…A8 | 各 100 µL 稀释液 |

依次混匀并向下一孔转移 100 µL，最后混匀 A8 并从 A8 弃去 100 µL。
播完后 A1…A8 体积均为 100 µL，浓度依次为 100、50、25 … 100/128 µM（即 781.25 nM）。


## 使用说明

- **单步执行 / 上一步 / 重置**：逐帧推演；**连续播放**每 0.9 秒自动推进一步。
- **滑块**：任意回看历史帧（失败后也可拖动查看此前的有效状态）。
- **步骤编排**：右侧列表可
  - 拖动 ⠿ 手柄**重排**；
  - 点 ✎ **编辑**孔位、体积、浓度、样本名、备注；
  - 点 ✕ **删除**；
  - 用「+ 加样/稀释液 / 混匀 / 转移 / 弃去」**新增**步骤。
- **吸头**：每步可选「每步新吸头」或「复用吸头组」并填写组名。同组吸头在同一条稀释链内复用是安全的；一旦吸头上残留的外来样本接触别的孔，该步立即报 `CARRYOVER`。面板底部显示各组吸头当前残留的样本。
- **本地保存**：所有编辑自动写入浏览器 `localStorage`（键 `pipette-sandbox:protocol:v1`），刷新不丢失；右上角「恢复内置方案」可还原。
- 任何步骤的增删改或重排都会让系统**从空板按当前顺序重新推演**，播放位置归零，绝不保留旧结果。

## 孔板读法

- **孔内液位高度** = 体积（满刻度 200 µL），数字同时直读体积；
- **液体颜色** = 浓度，蓝色顺序色阶按相对最高浓度做 log 映射（二倍稀释每级视觉等距），颜色旁始终有数值，不纯靠颜色；
- **黄色斜纹** = 该孔有液体但未混匀；
- **红色脉冲描边** = 当前失败步骤涉及的孔；
- 点选任意孔，下方显示体积、浓度、混匀状态与样本组成。

## 项目结构

```
src/
  engine/            # 纯函数模拟引擎（不依赖 React/DOM）
    types.ts         # 步骤、孔状态、帧、错误类型
    plate.ts         # 96 孔板常量、200 µL 容量
    protocol.ts      # 内置 A1→A8 方案与步骤 id 生成
    simulator.ts     # simulate()：逐帧推演、四类失败检测、首错停止
    storage.ts       # localStorage 读写
  components/        # Plate / StepList / StepEditor
  lib/               # 颜色映射、数值格式化、步骤描述
  test/              # Vitest 引擎测试 + Testing Library 组件测试
```

### 引擎模型

- 每个孔保存按样本分别记账的**物质量** `amounts[sample]`（单位 µM·µL），浓度恒等于 `Σamount / volume`；
- 转移按源孔当前组成**等比例**移走物质量，因此质量守恒对每次操作精确成立；弃去同理（物质量随液体离开孔板）；
- 进液后孔标记为「未混匀」（空孔首装天然均匀），混匀后置回，从未混匀孔吸液即拦截；
- 每个复用吸头组记录吸头上累积的样本 id；转移时仅在吸液阶段对照源孔判定带入（吸入源液后注入目标孔是稀释链的正常传播，不误报）。

## 测试覆盖

- `serialDilution.test.ts` —— 内置二倍稀释浓度链、各孔体积、弃去前后浓度不变；
- `massConservation.test.ts` —— 加样、转移、混匀、弃去的体积/物质量守恒；
- `capacity.test.ts` —— 200 µL 溢出、超余量吸空、边界值（恰好 200、恰好取空）、空孔混匀；
- `tipState.test.ts` —— 新吸头、同链复用安全、跨样本带入拦截、不同复用组隔离、脏吸头进稀释孔；
- `reorder.test.ts` —— 重排导致未混匀拦截、浓度链断裂、删除混匀步、推演无状态残留、修正后旧失败消失；
- `App.test.tsx` —— 初始空板、单步、连续播放自动停止、首错停止与历史帧回看、编辑后归零重算、localStorage 持久化、溢出端到端拦截。
